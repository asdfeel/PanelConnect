# **App Name**: PanelPlace

## Core Features:

- Job Listing: Display available panel and tasting jobs with details such as title, company, location, pay, and period.
- Search and Filter: Allow users to search for jobs based on keywords and filter by category, location, and pay.
- Bookmark Jobs: Enable users to save favorite jobs to a bookmark list for easy access.
- Job Application: Allow users to apply for jobs directly through the app. Generative AI can act as a tool that determines whether or not a brief cover letter is needed, based on keywords from the job requirements
- User Profile: Allow users to manage their profile information, such as name, email, and notification settings.
- My Applications: Allow users to track jobs they have applied for.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) for a fresh and inviting feel.
- Background color: Very light gray (#F0F8FF) for a clean and modern look.
- Accent color: Soft teal (#70DBD1) for highlighting interactive elements.
- Body and headline font: 'PT Sans', a humanist sans-serif font that combines a modern look with some warmth.
- Use Material Icons for a consistent and recognizable visual language.
- Maintain a clean and organized layout with clear sections and ample spacing.
- Implement subtle animations for transitions and loading states to enhance user experience.
